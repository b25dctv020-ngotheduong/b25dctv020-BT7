# Máy tính React

Ứng dụng máy tính đơn giản được xây dựng bằng React và Vite. Giao diện có các
nút số, bốn phép tính cơ bản, nút xóa và nút tính kết quả.

## Yêu cầu

- Node.js phiên bản LTS
- npm

## Chạy ứng dụng

Mở terminal trong thư mục `Calculator` và chạy:

```bash
npm install
npm run dev
```

Mở địa chỉ local được Vite hiển thị trong terminal, thường là
`http://localhost:5173/`.

## Build

Để tạo bản build production:

```bash
npm run build
```

Các file build được tạo trong thư mục `dist`.
